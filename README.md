\# Credit Card Analysis Dashboard



\## Project Overview



This project analyzes credit card customer and transaction data using Power BI and SQL.



The dashboard focuses on revenue, transaction amount, transaction count, interest, customer segments, card categories, and transaction trends.



\## Objective



\- Analyze credit card revenue and transaction performance

\- Identify high-revenue customer segments

\- Analyze weekly and quarterly transaction trends

\- Compare card categories, transaction methods, and expenditure types

\- Generate actionable business insights

\## Key Insights



\- Overall revenue: \*\*57M\*\*

\- Total interest: \*\*8M\*\*

\- Total transaction amount: \*\*46M\*\*

\- Blue card contributed approximately \*\*83.5% of total revenue\*\*

\- Q4 recorded the highest quarterly revenue and transaction count

\- Swipe transactions generated the highest revenue

\- Bills was the highest-revenue expenditure category

\- Businessman was the highest revenue-contributing job segment

\- Customers aged 40–50 generated the highest revenue

\- High-income customers contributed the highest revenue



\## Week-on-Week Analysis



\- Revenue increased by \*\*28.8%\*\*

\- Total transaction amount increased by approximately \*\*21%\*\* from the first week to the last week

\- Transaction count decreased by approximately \*\*6.3%\*\* from the first week to the last week
